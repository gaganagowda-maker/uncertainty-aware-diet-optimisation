# Uncertainty-Aware Diet Optimisation
MSc Data Science Dissertation — Aston University (RCA3)
Supervisor: Dr Roberto C. Alamino

## What this project does
Builds and compares four optimisation models to find the cheapest 
nutritionally adequate weekly meal plan for UK adults, accounting 
for uncertainty in food composition data.

Models: Baseline LP, Bertsimas-Sim Robust LP, 
Bonferroni Chance-Constrained LP, SOCP

## How to run
1. Install dependencies: pip install -r requirements.txt
2. Place Diet_Dataset_Extended.xlsx in the same folder as pipeline_v4.py
3. Open pipeline_v4.py in Jupyter Notebook
4. Run cells in order from Cell 1 to Cell 14

## Requirements
Python 3.11, Jupyter Notebook
See requirements.txt for full list of libraries
